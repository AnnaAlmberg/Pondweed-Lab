# Pondweed Lab

An interactive simulation of the *Elodea* (pondweed) photosynthesis experiment for VCE Biology Unit 1, Key science skills.

Students choose an independent variable, write a hypothesis, run trials, check for a fair test, and complete a discussion and conclusion. Results are sent to the teacher through a Google Form, and the Class results page collects, marks and prints each student's lab report.

**Open the lab:** https://annaalmberg.github.io/pondweed-lab/
